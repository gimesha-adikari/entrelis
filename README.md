# Entrelis

> **Everything is connected. Pick somewhere to start.**

Entrelis is an interactive map of knowledge built around **connections between ideas**, not isolated pages.

Start with a concept, explore its neighboring ideas, understand *why* they connect, and keep following the path across science, technology, history, philosophy, psychology, biology, mathematics, and more.

## Vision

Traditional encyclopedias are good at answering:

> What is this?

Entrelis also wants to answer:

> What is this connected to? Why? Where should I explore next?

The experience should feel like exploring a living map of ideas rather than browsing a database or talking to a generic chatbot.

## Initial focus

The first version will focus on **science + technology + human thought**, beginning with:

- Programming & computer science
- AI & mathematics
- Physics & space
- Biology & the human brain
- Psychology & philosophy
- History, inventions & civilization

## First vertical slice

The first polished knowledge path will be:

**Rust → Ownership → Memory → Stack & Heap → Operating Systems → CPUs → Transistors**

This slice will prove the graph interaction, concept pages, relationship explanations, navigation model, URLs, mobile experience, and visual direction before the knowledge graph grows.

## Technical direction

- Next.js
- TypeScript
- React
- Modern CSS
- Structured concept + relationship data
- 2D graph first; WebGL/Three.js only where it genuinely improves the experience
- Accessible DOM-based content alongside spatial graph exploration
- AI as an enhancement layer, not the source of truth

The exact database and graph libraries will be selected after an early technical spike.
